首页视图 + 首页卡片：在 COST 行下增加 opencode 与 pi 各自的 cost。细节页（models 视图）和 models 卡片不在本次范围。

样本数据（opencode + pi 之和 = 合计）：DeepSeek 合计 today ¥5.35 / week ¥8.98 / month ¥8.98 / all ¥8.98；其中 opencode today ¥3.92 / week ¥7.42 / month ¥7.42 / all ¥7.42，pi today ¥1.43 / week ¥1.56 / month ¥1.56 / all ¥1.56。

一、首页 UI（终端，80 列）

现有 DEEPSEEK 块只有 BALANCE + COST 两行。下面 3 个方案都在 COST 行下加 opencode / pi 子行，区别在信息密度。

  ╭────────────────────────────────────────────────────────────────────╮
  │ ● DEEPSEEK                                                        │
  │   BALANCE   ¥99.80                                                │
  │   COST      today ¥5.35  ·  week ¥8.98  ·  month ¥8.98  ·  all ¥8.98 │
  │   opencode  today ¥3.92  ·  week ¥7.42  ·  month ¥7.42  ·  all ¥7.42 │
  │   pi        today ¥1.43  ·  week ¥1.56  ·  month ¥1.56  ·  all ¥1.56 │
  ╰────────────────────────────────────────────────────────────────────╯

推荐 · 方案 A子行与 COST 同缩进、键名对齐，四周期全显。子行整体用 dim 灰，与 COST 的白色形成主次。改动最小：`summary_lines` 复用即可。

  ╭────────────────────────────────────────────────────────────────────╮
  │ ● DEEPSEEK                                                        │
  │   BALANCE   ¥99.80                                                │
  │   COST      today ¥5.35  ·  week ¥8.98  ·  month ¥8.98  ·  all ¥8.98 │
  │   opencode   today ¥3.92  ·  all ¥7.42                                │
  │   pi         today ¥1.43  ·  all ¥1.56                                │
  ╰────────────────────────────────────────────────────────────────────╯

方案 B子行只保留 today / all 两列（week/month 可从 COST 行反推）。最紧凑，行更短，适合窄终端也不易折行。

  ╭────────────────────────────────────────────────────────────────────╮
  │ ● DEEPSEEK                                                        │
  │   BALANCE   ¥99.80                                                │
  │   COST      today ¥5.35 (op ¥3.92 · pi ¥1.43) · week ¥8.98 ·     │
  │             month ¥8.98 · all ¥8.98                               │
  ╰────────────────────────────────────────────────────────────────────╯

方案 C不增行，只在 today 数值后括号注 op / pi。最省空间，但只有 today 被拆，week/month/all 看不到来源占比，且折行后括号容易跟丢。
